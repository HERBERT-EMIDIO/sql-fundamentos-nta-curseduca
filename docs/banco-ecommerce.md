# Banco e-commerce (anotações)

Modelo usado na [TrilhaSQL](https://github.com/ckoliveiraa/TrilhaSQL) do prof. Carlos Oliveira.

## Tabelas

| Tabela | Para que serve (resumo) |
|--------|-------------------------|
| `categorias` | Categorias de produtos |
| `produtos` | Catálogo |
| `clientes` | Clientes |
| `pedidos` | Pedidos |
| `itens_pedido` | Itens de cada pedido |
| `pagamentos` | Pagamentos |
| `avaliacoes` | Avaliações de produtos |

## Relacionamentos (visão simples)

- Uma categoria tem vários produtos  
- Um cliente faz vários pedidos  
- Um pedido tem vários itens e pode ter pagamentos  
- Produto e cliente participam de avaliações
