## Como estudar (fluxo sugerido)

1. Assista a aula no Curseduca  
2. Crie um arquivo `.sql` na pasta do módulo  
3. Documente o aprendizado em `docs/notas-de-aula.md`  
4. Faça commit com mensagem clara  

Exemplo de mensagem:

```text
feat(01): adiciona consultas SELECT basicas da aula 1
```

---

## Boas práticas

- Não versionar dumps grandes nem dados sensíveis  
- Não colar material copyrighted da plataforma; escreva **suas** notas  
- Prefira um arquivo por aula: `aula-01-select.sql`
